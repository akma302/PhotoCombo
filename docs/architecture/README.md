# PhotoCombo Architecture Atlas

Учебный архитектурный атлас по исходникам `7351a27b9daa140471cae8295a4aca88441ca572`, 14 ноября 2026.

- **[Открыть просмотрщик](open-atlas.html)** — главы, масштаб, поиск, анимация.
- **[Единый SVG](PhotoCombo-Architecture.svg)** — 1920 × 20700, 15 листов, весь материал в одном файле.
- **[Onboarding в браузере](ONBOARDING.html)** — подробный разбор сценариев, границ, владения, рисков и маршрута изучения; [версия Markdown](ONBOARDING.md).
- **[Полный индекс](SOURCE_INDEX.md)** — 135 Main-файлов и 78 файлов тестов.
- **[Проверки](VALIDATION.md)** — что проверено и что не измерялось.

SVG-главы самостоятельны, не требуют внешних шрифтов, CDN или JavaScript. Карточки с ↗ ведут в локальные исходники. Для сохранения этих ссылок переносите всю папку вместе с репозиторием. При копировании только SVG его визуальное содержимое сохраняется, но ссылки на исходники будут относиться к прежней структуре каталогов.

Генератор `build_atlas.py` использует только стандартную библиотеку Python. `source-manifest.json` фиксирует пути и хеши исходников. Смысловые схемы требуют проверки человеком при изменении проекта; подробности в Onboarding.
