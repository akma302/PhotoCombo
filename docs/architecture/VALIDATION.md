# Проверка архитектурного атласа

Источник: `7351a27b9daa140471cae8295a4aca88441ca572`, 14 ноября 2026. Изменения относятся к документации; Kotlin, Gradle и пользовательские данные не менялись.

## Проверяемые свойства

- Полнота manifest сверяется с отслеживаемыми Git-файлами: 135 Main-файлов, включая test-support, и 78 файлов тестов.
- SHA-256 каждого Main-файла сверяется с текущим исходником.
- Production project-зависимости всех 11 модулей сверяются с moduleDependencies из корневого build.gradle.kts.
- Все 16 SVG (15 листов + единый атлас) разбираются XML-парсером; проверяются уникальность ID и локальные ссылки.
- Проверяются ссылки в Markdown, UTF-8 без BOM, LF и отсутствие хвостовых пробелов.
- Все 15 отдельных листов отрисовываются headless Microsoft Edge. Проверяются границы текста, пересечения текста внутри карточек/примечаний и отсутствие выхода за лист.
- Проверяется `prefers-reduced-motion`, поиск главы, масштабирование и выключатель анимации в просмотрщике, открытом через `file://`.
- Просмотрщик проверяется на ширинах 390, 768, 1280, 1920 и 2560 px; горизонтальная прокрутка страницы отсутствует. Прокрутка увеличенной схемы внутри её области предусмотрена.
- Контактный лист глав, крупный лист Builder и узкий просмотрщик визуально осматриваются отдельно от автоматических измерений.

Итоговый прогон: **15 листов — без найденных ошибок вёрстки; просмотрщик — без ошибок сценариев; локальные ссылки корректны**. Сверка исходников и графа 11 модулей пройдена. HTML-издание Onboarding проверено дополнительно: 11 разделов, оглавление, ширины 390 и 1440 px.

## Воспроизведение

Из корня репозитория:

```powershell
python docs\architecture\build_atlas.py
node docs\architecture\render_guide.cjs '<путь к node_modules с marked>'
python docs\architecture\check_sources.py
node docs\architecture\validate_atlas.cjs '<путь к node_modules с playwright и sharp>'
git diff --check
```

Browser-проверка использует установленный Microsoft Edge и записывает PNG + report.json в `build/architecture-qa/`. Для запуска в среде с sandbox может потребоваться разрешение на headless browser. Зависимости Playwright/Sharp нужны только для проверки, не для открытия результата. `preview.png` — уменьшенное изображение титульного листа.

## Границы результата

Это статический архитектурный разбор исходников. Полный Gradle check и приложение при подготовке атласа не запускались: runtime-код не изменялся. Наличие 78 файлов тестов не означает новый успешный прогон этих тестов. Замеры памяти, профилирование, воспроизведение гонок и проверка shutdown не выполнялись. Соответствующие замечания обозначены как наблюдения по коду и риски для дальнейшей проверки.

Индекс объявлений — поиск top-level строк, не Kotlin AST. Смысловые связи вручную отобраны для объяснения архитектуры; это не полный граф каждого вызова метода. Генератор обновляет индекс и граф модулей, но требует ручного пересмотра описательных схем при изменении реализации.
