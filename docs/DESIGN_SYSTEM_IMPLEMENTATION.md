# Реализация UI-компонентов

Статус: компоненты интегрированы в `main` через PR #5. Визуальный контракт —
`docs/DESIGN_SYSTEM.md` v0.8 (путь от корня); ниже — состав и свидетельства реализации.
Общая ветка реализации: `feature_0005_uiComponents`.
Изолированные рабочие копии используются для параллельной реализации; интеграция
компонентов производится merge-коммитами с сохранением отдельных веток.

## Использование

Токены/тема/примитивы/иконки/компоненты располагаются в подпакетах
`com.combo.ui.common.designsystem`. Общий код использует `PcTheme`, desktop-хост —
`com.combo.ui.common.PcDesktopTheme`. Файлы системных шрифтов не входят в репозиторий.

```kotlin
PcDesktopTheme {
    PcSurface {
        PcButton(
            text = "Save",
            onClick = onSave,
            variant = PcButtonVariant.Primary,
            icon = PcIcons.Check,
        )
    }
}
```

Ввод и семантика остаются в Foundation (`clickable`, `toggleable`, `selectable`,
`BasicTextField`). Внешний вид, геометрия и feedback задаются собственными
Layout/Canvas/Modifiers. Направленные иконки зеркалируются в RTL. Выборы и текст
передаются снаружи, компоненты не создают бизнес-состояние.

## «Графит · тон» (история реализации v0.3)

Утверждён светлый нейтральный accent `#DCE1E6`, onAccent `#1C2528`, hover `#35383E`,
pressed `#41454C` и focusFill `#3A3C41`. Остальные роли Dark остаются прежними.
Контракт `PcTheme.focus` объединяет высоту внутреннего градиента 10 dp с alpha 0.14
и нижнего мягкого свечения 4 dp с максимальной alpha 0.35. Полоса толщиной 2 dp
обрезается shape; внешнего прямоугольника вокруг контрола нет. `focusOffset` 2 dp
означает свободное пространство, gutter `PcActionGroup` 4 dp сохраняется для свечения.

Кнопки, checkbox, сегменты и select показывают индикатор только при клавиатурном
вводе. Поле показывает также фокус редактирования мышью. Primary сохраняет свою
заливку, использует полосу onAccent и светлое свечение accent; ошибочное поле сохраняет
danger-границу, текст ошибки и danger-индикатор фокуса. Геометрия, hit test,
callbacks и runtime-векторы не меняются.

Изменения реализации и документации интегрируются отдельными ветками из таблицы.
Проверка v0.3 от 2026-10-22 на Windows: полный `desktopTest` — **411 тестов, 0 failures,
0 errors, 1 skipped** (не задан опциональный каталог личных фотографий). Обновлены
84 PNG галереи по 12 сочетаниям ширины/density/fontScale; фактический шрифт — Segoe UI.
Просмотрены фокус основной кнопки, поле ввода на узком экране при density 1.5 и
fontScale 1.25, диалог. Пиксельные тесты проверяют градиент и нижнее свечение при
density 1.0/1.5, fontScale 1.0/1.25 и LTR/RTL, непрозрачную полосу, отсутствие
внешней рамки сверху/сбоку, прежние bounds и исключение свечения из hit area.
Реальными событиями проверены mouse → Tab, mouse → Enter, mouse → стрелка сегмента,
редактирование поля с ошибкой, busy/disabled. Переключение DPI Windows и ручной
обход отдельного окна не выполнялись.

## Воспроизводимая галерея

Запуск: `./gradlew.bat :composeApp:runDesignSystemGallery`.
Это отдельное окно без DI, базы и личной библиотеки; оно показывает настоящие
компоненты, допускает ввод текста, выбор режима/формата, открытие меню и диалога.
Обычный запуск PhotoCombo продолжает открывать продуктовые экраны.

Полная проверка: `./gradlew.bat :composeApp:desktopTest --offline --console=plain`.
Только компоненты: `./gradlew.bat :composeApp:desktopTest --tests '*designsystem*' --offline`.

`ComponentGalleryTest` создаёт PNG в `composeApp/build/ui-previews/design-system/`
для ширин 420/800/1200 dp, density 1.0/1.5 и fontScale 1.0/1.25:

- `top` и `bottom` — части прокручиваемой галереи;
- `focus`, `hover`, `pressed` — реальные состояния кнопки от focus/pointer input;
- `menu`, `dialog` — поверхности открытых платформенных слоёв;
- `font.txt` — фактически выбранный системный шрифт.

Галерея проверяет ввод текста с пробелами, переключение флажка, прямой выбор значения,
Escape и изменение ширины/плотности/шрифта. Компонентные тесты отдельно проверяют
Tab, RTL, роли/имена, disabled/busy, отмену нажатия, индикатор фокуса, динамические options,
открытое меню при resize и callback ровно один раз. Векторные тесты проверяют реальные
границы paths со stroke и кэширование экземпляров.

Поле `Required name` — редактируемый пример валидации: пустое или состоящее только
из пробелов значение показывает `Enter a name`; ввод имени снимает ошибку.

Density в тесте моделирует масштаб клиентской сцены; тест не переключает настройки
Windows и не доказывает поведение её системной строки заголовка. Проверка через
скриншоты галереи и автоматические действия не является ручной проверкой всех
контролов в работающем приложении.

Проверка v0.2 от 2026-10-22 на Windows: полный `desktopTest` — **403 теста, 0 failures,
0 errors, 1 skipped** (опциональная проверка импорта личного каталога фотографий).
Созданы 84 PNG по 12 комбинациям размеров/density/fontScale. Фактический шрифт —
Segoe UI. Просмотрены снимки широкой и узкой галереи, состояний контролов и диалога;
снимки помогли выявить и закрыть перенос короткой подписи сегмента. Ручной обход
галереи мышью в отдельном окне и переключение системного DPI не выполнялись.

## Плоский фокус (v0.4)

Ветка `feature_0034_flatFocus`: внутренний градиент и внешнее свечение отключены
в стандартной теме (innerAlpha/haloAlpha = 0). Тональная заливка и нижняя полоса
сохранены. Отдельный пиксельный тест проверяет ровную заливку и отсутствие света
за нижним краем. Проверки опционального света явно включают его собственным PcFocus;
галерея использует стандартный плоский фокус.

Проверка v0.4: полный `desktopTest` — 412 тестов, 0 failures/errors, 1 skipped.

## Красный рубин (v0.5)

Danger-текст и ошибки используют #E07894; DangerFilled — #8B2744 с текстом
#F8EAF0. В галерее представлены прозрачная и заполненная кнопки удаления.
Заполненная кнопка сохраняет бордовую поверхность при клавиатурном фокусе;
полоса фокуса светлая, без свечения. Hover/pressed остаются в рубиновой палитре.
Продуктовые сценарии удаления и подтверждения не меняются.

Проверка v0.5: полный `desktopTest` — 413 тестов, 412 passed, 0 failures/errors,
1 skipped (не задан каталог личных фотографий). Пиксельный тест проверяет normal,
hover, pressed, сохранение заливки и светлую полосу клавиатурного фокуса;
проверены контраст и однократная активация. Обновлены 84 снимка галереи при трёх
ширинах, двух density и двух fontScale. Снимок 800 dp просмотрен визуально;
ручная проверка в отдельном окне не выполнялась.

## Builder (v0.6)

`feature_0038_builderDesignSystem`: шапка, настройки холста, инспектор 240 dp от
760 dp, строка вида, выбор/замена фото и выход используют Pc-компоненты и PcIcons.
Desktop-хост передаёт Segoe UI. Рабочее поле — workspace с отступами 32/20 dp;
подпись выбранной рамки и маркеры на гранях рисуются отдельно от общего рендера.
Инспектор сворачивается без изменения drafts/Undo, узкая компоновка сохраняет инструменты.
SnackbarHost/State остаются инфраструктурой очереди сообщений; их содержимое рисуется
PcSurface/PcText. Рендер, жесты, сохранение и хранилище не переписываются.

Полный desktopTest: 415 тестов, 414 passed, 0 failures/errors, 1 skipped
(не задан каталог личных фотографий). Добавлены проверки сворачивания и 12 сочетаний
ширины 420/800/1200 dp, density 1/1.5, fontScale 1/1.25 с цветными фикстурами.
PNG: `composeApp/build/ui-previews/builder-ds-*.png`. Просмотрены широкий снимок
и узкий при density 1.5/fontScale 1.25. Проверка положения инспектора обновлена
под утверждённый breakpoint 760; проверки событий, сохранения и жестов сохранены.
Ручная проверка окна и переключение системного DPI не выполнялись.

## Компоновка инспектора и трек режимов (v0.7)

`bug_0041_builderInspectorLayout` интегрирует `bug_0042_segmentTrack` и
`bug_0043_inspectorGroups`. Сегменты получили общий border-трек с inset 3 dp и
центрирование содержимого; интерактивная высота не уменьшилась, трек стал 40/50 dp.
В инспекторе восстановлены полные группы из макета, левый флажок, подпись Replace,
ряд действий и разделитель. Add photo прижат к правому краю панели; статус находится
рядом с именем, а фон шапки/панелей — panel.

Проверка: полный desktopTest — 428 тестов, 427 passed, 0 failures/errors, 1 skipped

Проверены ширина/выравнивание групп, отсутствие перекрытий, callbacks и перенос при
fontScale 1.25. Builder снимается в Frame и Photo по 12 сочетаниям ширины/density/fontScale;
изолированные снимки инспектора — `composeApp/build/ui-previews/builder-inspector-*.png`.
Просмотрены Photo 1200 dp и Photo 420 dp при density 1.5/fontScale 1.25, Frame 800 dp.
Действия проверялись автоматикой; ручной обход приложения и смена системного DPI не выполнялись.

## Остальные продуктовые экраны (v0.8)

Общая ветка — `feature_0045_remainingScreensDesignSystem`; части:
`feature_0046_libraryDesignSystem`, `feature_0047_comboListDesignSystem`,
`feature_0048_viewerDesignSystem`. Две независимые части реализованы параллельно
в отдельных worktree, общая навигация и визуальные изменения сетки интегрированы отдельно.

Библиотека использует Pc-панели, переносимые действия и сообщение с Dismiss;
Import находится в шапке и доступен при пустом списке и выборе. Сетка сохраняет
правый/Ctrl+клик и порядок выбора; выделение использует PcIcons.Check и accent.
Список комбо использует адаптивные карточки (breakpoint 600 dp), New combo в
шапке, собственную иконку Edit и прежний путь drawCombo для превью. Просмотр
использует panel-шапку и workspace вокруг фото; сохраняет pager, масштаб и стрелки.
Нижняя навигация использует PcSegmentedControl. Бизнес-логика и хранение не изменены.

Полный `:composeApp:desktopTest --offline`: 440 тестов, 439 passed,
0 failures/errors, 1 skipped (опциональные личные фото). Проверены существующие
сценарии навигации, выбора, редактора, Undo и сохранения; добавлены UI-проверки
импорта, сообщений, пустых состояний, команд списка и просмотра. Новая иконка
включена в общие проверки геометрии и кэширования PcIcons.

Снимки настоящего CMP-кода: `composeApp/build/ui-previews/library/`,
`composeApp/build/ui-previews/combo-list/`, `composeApp/build/ui-previews/viewer-*.png`.
Сцены используют синтетические изображения; библиотека снята при 420/1200 dp,
список при 420/600/1200 dp, просмотр при 420/1200 dp, включая density 1.5 и
fontScale 1.25. Просмотрены узкая библиотека с выделением, список 600 dp с
крупным шрифтом и узкий просмотр с длинным именем; исполнители также просмотрели
широкие, пустые состояния и сообщения. Density относится к сцене, а не системному DPI.
Ручной обход окна, системный DPI и Ctrl+клик в реальном окне не проверялись;
обработчик Ctrl+клика сохранён, правый клик покрыт существующими тестами.
